# Dataset ngoài Git

Khôi phục dataset đã khóa từ bundle Drive được chỉ trong `../ARTIFACTS.json`. Dataset chỉ gồm accepted train/validation và metadata chống trùng; không dùng ảnh test/external để phát triển. Không trỏ trực tiếp vào CSV/split landmark của hai mô hình khác để thay thế release auto V2. Giữ nguyên fingerprint và checksum trong cấu hình.
